# Stateful 工作流评估

[English version](README.md)

`stateful-scenarios.json` 是一套面向模型的小型语料，覆盖长时间 Blender VSE 对话中的
关键决策：正向与负向路由、定向读取、令牌消耗、幂等重试、人工修改、过期游标、检查点
隔离、访问拒绝、缺少工具和上下文压缩。

`tests/evals/stateful_workflow.py` 首先通过确定性判定器回放每个预期状态转换，然后针对真实
的有界上下文投影器和恢复胶囊构建器运行 250 个合成编辑循环。报告会比较直接累积工具
结果所占的字节数，以及宿主每 25 轮压缩一次上下文时的最大活跃字节数。

`baseline.json` 将最低语料覆盖率和最高上下文增长阈值与观测参考值分开保存。有意修改
协议时，应先更新实现和场景，经审阅后再更新基线；不得仅为通过回归测试而放宽基线。

该判定器是一份可执行契约，并不保证语言模型一定会选择正确动作。以后可以让候选模型
运行相同的提示词；请记录所选工具和参数，但不要为了迎合某个模型的输出而修改预期场景
文件。
