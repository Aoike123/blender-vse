# Stateful 工作流评估

[English version](README.md)

`stateful-scenarios.json` 是面向模型的小型语料，覆盖长 Blender VSE 对话中的关键决策：正向与负向路由、目标读取、令牌消耗、幂等重试、人工修改、过期游标、检查点隔离、访问拒绝、缺少工具和上下文压缩。

`tests/evals/stateful_workflow.py` 首先通过确定性 Oracle 回放每个预期状态转换，然后针对真实有界上下文投影器与恢复胶囊构建器运行 250 个合成编辑循环。报告会比较朴素累积的工具结果字节数与宿主每 25 轮压缩时的最大活跃字节数。

`baseline.json` 把最低语料覆盖和最高上下文增长阈值与观察到的参考值分开保存。有意修改协议时，先更新实现和场景，审阅后再更新基线；不能只为了让回归通过而放宽。

Oracle 是可执行契约，不声称语言模型一定会选择正确动作。以后可以对候选模型运行相同 Prompt；记录所选工具和参数，但不要为了适应单个模型输出而修改预期场景文件。
